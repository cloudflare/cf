# Wrangler compatibility tests

This package runs canonical Wrangler test situations against cf. The pinned
revision, inventory shape, and regeneration command are documented in
`README.md`; `MANIFEST.md` is the generated inventory.

## Canonical identities

- Upstream test names and `describe()` ancestry are canonical identities. Do
  not rename or delete them when adapting command paths or assertions for cf.
- A passing test is executable parity evidence. Use `it.todo()` when the
  behavior belongs in cf but is not working or ported yet. Use `it.skip()` only
  for Wrangler internals or behavior that deliberately conflicts with cf's
  design.
- Missing upstream identities default to todo. Broad skip rules require
  explicit review; do not turn unaudited behavior into an intentional
  divergence.
- Normal ported tests take precedence over generated fallback classifications.

## Generated inventory

- `src/__tests__/upstream/unported-*.test.ts` and `MANIFEST.md` are generated by
  `scripts/generate-upstream-stubs.mjs`. Do not edit individual manifest rows
  or fallback identities by hand.
- The generator requires complete Vitest JSON reports, not `vitest list`
  output. It uses full ancestry when leaf titles repeat and preserves expanded
  parameterized cases.
- Rebase the corpus atomically: update the pinned revision/banner,
  classification rules, every fallback shard, and the full manifest in one
  reviewable change.

## Verification

Run `pnpm generate` from the repository root after OpenAPI or Forge changes,
then run `pnpm test` from this package. Its `pretest` script builds the CLI with
the test-specific tsdown configuration, and tests import the resulting
`../cli/dist/index.mjs`. The test build keeps mock-sensitive dependencies
external while the normal production build bundles them. `pnpm test:watch`
also builds the test bundle once before starting Vitest.
